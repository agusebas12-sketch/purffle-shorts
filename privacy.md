Política de privacidad de Purffle Shorts

Última actualización: 28 de octubre de 2026

Purffle Shorts es un proyecto de generación y automatización de vídeos cortos para redes sociales.

Información que recopilamos

La información que se procesa depende de las funciones que el usuario decida utilizar. Si se incorporan funciones de inicio de sesión o publicación en redes sociales, podrán procesarse los datos necesarios para prestar esas funciones.

Uso de la información

La información se utiliza para operar, mantener y mejorar las funciones de Purffle Shorts, y para permitir las acciones que el usuario autorice.

Servicios de terceros

Purffle Shorts puede integrarse con plataformas externas, como TikTok, YouTube e Instagram. El uso de estas plataformas también está sujeto a sus propias políticas de privacidad y condiciones.

Seguridad

Adoptamos medidas razonables para proteger la información. Ningún sistema puede garantizar una seguridad absoluta.

Cambios en esta política

Esta política podrá actualizarse cuando cambien las funciones del proyecto.

Contacto

Para consultas sobre esta política de privacidad, utiliza el canal de contacto que se publique en la página oficial de Purffle Shorts.
